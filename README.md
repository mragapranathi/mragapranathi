### 🗑️ Agentic AI Smart Waste Collection & Recycling Optimization System

[![Repo](https://img.shields.io/badge/GitHub-Repository-181717?style=for-the-badge&logo=github)](https://github.com/mragapranathi/Agentic-AI-Smart-Waste-Collection-Recycling-Optimization-System)
[![Live Demo](https://img.shields.io/badge/Frontend-Live%20on%20Vercel-000000?style=for-the-badge&logo=vercel)](https://frontend-five-lime-80.vercel.app)
[![API](https://img.shields.io/badge/Backend-Live%20on%20Render-46E3B7?style=for-the-badge&logo=render)](https://smartwaste-backend-gb09.onrender.com/docs)

</div>

> An autonomous municipal waste-management platform powered by **8 specialized AI agents** orchestrated via **LangGraph**. Features real-time IoT sensor processing, Random Forest fill-level forecasting (R² = 0.97), Google OR-Tools CVRP route optimization, human-in-the-loop approval, and dynamic route replanning.

| Layer | Tech |
|---|---|
| 🤖 Agent Framework | LangGraph · 8 Specialized Agents |
| 🧠 ML Model | Random Forest · MAE: 1.64% · R²: 0.97 |
| 🗺️ Route Optimization | Google OR-Tools · CVRP · Guided Local Search |
| ⚡ Backend | FastAPI · SQLAlchemy · PostgreSQL |
| 🎨 Frontend | React 19 · TypeScript · Tailwind CSS · Leaflet.js |
| 📊 Analytics | Recycling Rates · KPI Dashboard · PDF Reports |
